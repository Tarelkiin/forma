## Публикация на GitHub Pages

Это отдельная статическая версия: без сервера и без связки с iPad. Каждый посетитель работает со своей сценой в браузере. Studio, Screen, seed, эффекты, камера и PNG-экспорт сохранены.

1. Распакуйте архив.
2. Создайте на GitHub репозиторий, например forma.
3. Загрузите СОДЕРЖИМОЕ этой папки в корень репозитория. Файл index.html должен находиться сразу в корне, рядом с engine.js, assets и vendor, а не внутри папки v12-github-web. Для загрузки папок удобно использовать GitHub Desktop.
4. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save.
5. Дождитесь публикации. Адрес будет указан в Pages: https://ВАШ-ЛОГИН.github.io/forma/.
6. Для обновления замените файлы и выполните commit/push.

Включите .nojekyll и .gitignore — они лежат в этой папке. Устанавливать npm-пакеты и запускать Node на GitHub не требуется. Ничего из этой папки автоматически не публикуется; репозиторий ещё не создан.

## Использование

Камера требует HTTPS и разрешения браузера. Модель сегментации и WASM находятся локально в папке сайта; изображения с камеры никуда не отправляются. Seed повторяет стартовую форму/оформление. Screen скрывает интерфейс редактора; Save PNG экспортирует без подписи и кнопок.

Изображение сохраняется локально. Если автоматическая загрузка не начинается, нажмите Download PNG, либо используйте Chrome/Edge. При обновлении страницы текущая сцена сбрасывается.

Не открывайте index.html двойным щелчком: ES-модулям нужен HTTP/HTTPS. Для локальной проверки используйте статический веб-сервер. При публикации GitHub Pages этот сервер предоставляет сам.
